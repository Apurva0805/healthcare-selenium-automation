# 🏥 Healthcare Selenium Automation Framework

## 📌 Project Overview

This repository contains an independent Healthcare QA Automation project developed to practice web application automation using **Java, Selenium WebDriver, TestNG and Maven**.

The project focuses on automating healthcare application workflows and validating important functional scenarios through reusable automation components.

## 🛠️ Technologies Used

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- XPath and CSS Locators
- Git and GitHub
- IntelliJ IDEA

## ▶️ How to Run the Project

### Prerequisites

- Java JDK
- IntelliJ IDEA or another Java IDE
- Maven
- Chrome browser

### Clone the repository

```bash
git clone https://github.com/Apurva0805/healthcare-selenium-automation.git
```

### Open the project

Open the cloned folder in IntelliJ IDEA and allow Maven dependencies to load.

### Execute tests

```bash
mvn clean test
```
